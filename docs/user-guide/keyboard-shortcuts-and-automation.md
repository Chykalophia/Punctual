# Keyboard shortcuts and automation

## Global keyboard shortcuts

Every shortcut is **unassigned by default**, so Punctual never takes a key combination you already use. Set them in [Preferences ▸ General ▸ Keyboard shortcuts](preferences/general.md). They work from any app.

| Shortcut | What it does |
|---|---|
| Open the dropdown | Opens the [dropdown](dropdown.md) |
| Open the calendar window | Punctual's own month view |
| Open the search bar | The [command bar](windows.md#search-bar-command-bar) |
| Open the world clock | The [world clock](windows.md#world-clock) |
| Join my next meeting | |
| Join the link on my clipboard | |
| Check my camera and mic | [Camera check](windows.md#camera-check) |
| Start a new call | On the service set in [Joining](preferences/joining.md) |
| Add an event to my calendar | The [event editor](windows.md#event-editor) |
| Hide the meeting title in the menu bar | For screen-sharing |

Inside the dropdown, ⌘N creates a new event. In the command bar, ↑ ↓ move, Return runs, Esc closes. In the calendar window, arrow keys move the selected day.

## `punctual://` links

Open these from a browser, Terminal (`open punctual://preferences`), or another app:

| Link | What it does |
|---|---|
| `punctual://preferences` | Opens Preferences |
| `punctual://dropdown` | Opens the dropdown |

## Shortcuts app

Punctual adds three actions to the Shortcuts app:

| Action | What it does |
|---|---|
| Get Nearest Event Details | Returns one detail of the current or next meeting: Title, Start Date, End Date, Meeting Link, Meeting Service, Calendar, URL, Notes, Location, or Attendees |
| Join Nearest Meeting | Joins the current or next meeting |
| Dismiss Nearest Meeting | Dismisses the current or next meeting |
