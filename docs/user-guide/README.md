# Punctual user guide

Punctual lives in your Mac's menu bar. It shows your next meeting, counts down to it, and joins it in one click. This guide walks through every place Punctual shows up on your screen, what each one looks like, and the settings that change it.

## About the screenshots

Almost every screenshot in this guide is generated by code, so it can be refreshed after any UI change. The few that show macOS itself (the menu-bar item, its right-click menu, a notification banner, an alert dialog, the camera check) are captured by hand and listed in [SCREENSHOTS.md](SCREENSHOTS.md). The app windows are rendered from built-in sample meetings, never from a real calendar, in both light and dark mode. See [SCREENSHOTS.md](SCREENSHOTS.md) for how to regenerate them.
