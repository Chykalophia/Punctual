- The app version and credits: Punctual is maintained by Chykalophia / Peter Krzyzek and built on MeetingBar by Andrii Leitsius.
- **GitHub**: opens the project page.
- **Contact**: opens a new email in your mail app (see [Emails](../emails-and-web-pages.md#contact)).
- **What's New**: opens the [What's New](../windows.md#whats-new) window.
- **Updates**: Check for updates automatically; Download and install updates automatically (installs when Punctual next quits); **Check for Updates…**; and when it last checked. A check asks GitHub whether a newer version exists; GitHub sees your IP address and Punctual version, never your calendars. Updates are signed and verified before they install.
- **Copy a report for support**: copies a diagnostics report with no calendar content (see [the example](../emails-and-web-pages.md#copy-a-report-for-support)). The button briefly reads "Copied".
